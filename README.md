# Customer Churn Intelligence System

## Project Overview

This project analyzes customer churn behavior using machine learning and business intelligence techniques.

The system identifies churn patterns, predicts high-risk customers, and recommends retention strategies through an interactive Power BI dashboard.

---

## Tools & Technologies

- Python
- Pandas
- Scikit-learn
- XGBoost
- SQL
- Power BI

---

## Features

- Churn prediction model
- Risk segmentation
- Revenue at risk analysis
- Retention recommendation engine
- Interactive dashboard

---

## Dashboard Insights

- Month-to-month customers showed highest churn
- Long-term contracts reduced churn significantly
- Early-tenure customers churned more frequently
- High-risk customers represented major revenue exposure
